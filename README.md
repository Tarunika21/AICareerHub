# AICareerHub

AICareerHub is an AI-powered career development platform designed to help users improve their career profile, analyze skills, build resumes, and receive personalized career recommendations.

## Tech Stack

### Backend
- ASP.NET Core
- C#
- PostgreSQL
- Entity Framework Core

### Frontend
- Angular

### Version Control
- Git
- GitHub

## Project Structure

- Backend - ASP.NET Core Web API
- Frontend - Angular application
